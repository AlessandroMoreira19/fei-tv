# Projeto FEI TV - Java & PostgreSQL

> **Vídeo de Apresentação:** Assista à demonstração do sistema no [YouTube](https://youtu.be/c6tYy0Z3pRQ).

---

## 1. Introdução
O **FEI TV** é uma aplicação desktop desenvolvida para catalogação, visualização e interação com conteúdos multimídia (filmes, séries e músicas). O sistema adota os princípios de Engenharia de Software e Interação Humano-Computador (IHC), integrando uma interface gráfica responsiva em **Java Swing** com persistência relacional em **PostgreSQL**.

---

## 2. Tecnologias Utilizadas
* **Linguagem:** Java (JDK 17 ou superior recomendado)
* **Interface Gráfica:** Java Swing
* **Banco de Dados:** PostgreSQL
* **Driver JDBC:** PostgreSQL JDBC Driver (`postgresql-42.x.x.jar`)
* **IDE Recomendada:** Apache NetBeans, IntelliJ IDEA ou VS Code

---

## 3. Pré-requisitos
Antes de executar o projeto, certifique-se de ter instalado em sua máquina:
1. **Java Development Kit (JDK 17+)**: com a variável de ambiente `JAVA_HOME` configurada.
2. **PostgreSQL**: serviço ativo localmente (porta padrão `5432`).
3. **IDE Java** (ex: NetBeans) ou **Git + Terminal**.
